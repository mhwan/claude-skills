# 비상 기사 목록 (빅카인즈 점검 때)

빅카인즈가 점검 중일 때 네이버 공식 뉴스 검색 API로 **기사 목록만** 만든다. 정식 브리핑·대관 보고서를 대신하지 않는다.

> 참고: 뉴스 스킬 3개(`daily-news-brief`, `korean-news-search`, `food-industry-watch`)는 이제 점검 때 스스로 「네이버 대체판 — 본문 미확인」으로 전환한다. 이 프로그램은 스킬 밖에서 단독으로 목록만 필요할 때 쓴다.

## 실행

`PY` 는 Windows `py -3 -X utf8`, macOS `python3`. 경로는 이 폴더의 절대경로로 쓴다.

```
PY "<이 폴더>/scripts/naver_list.py" check
PY "<이 폴더>/scripts/naver_list.py" brief YYYY-MM-DD
PY "<이 폴더>/scripts/naver_list.py" watch 시작일 종료일
```

- `check`: 키가 들어 있는지만 `True`/`False` 로 찍는다.
- `brief`: 7개사 조간 목록. 신문사별 건수, 사설, 여러 신문이 함께 다룬 이슈, 신문사별 기사 순서.
- `watch`: 대관 스킬의 뉴스 검색어(`watch.json`, 읽기만 함)로 찾은 기사 목록.
- 결과: `output/비상목록/`. 끝나고 건수와 "기간을 다 못 본 검색어" 수를 사용자에게 그대로 알린다.
- 시험: `PY "<이 폴더>/scripts/test_naver_list.py"` → 마지막 줄 `불일치 0건`. 인터넷을 쓰지 않는다.

## 할 수 없는 것

- 본문을 보지 않는다. 요약, 논조 비교, 원문 대조 검증이 없다. 목록의 기사 내용을 사실로 옮겨 적지 않는다. 필요하면 사용자가 원문 링크를 연다.
- 네이버 발췌는 저장하지 않는다. 언론사·네이버뉴스 페이지를 열지 않고, 링크가 살아 있는지도 검사하지 않는다.
- 이 프로그램의 목록은 정식 보고서에 합치지 않는다(스킬의 대체판은 표시·검사를 거쳐 「확인 필요」 행으로만 들어간다). 빅카인즈가 돌아오면 그 기간을 정식 절차로 다시 수집한다.

## 빠질 수 있는 기사

- 검색어 하나로 볼 수 있는 기사는 약 1,100건이다. 날짜를 지정해 찾는 기능이 없어 최신 기사부터 내려간다.
- 그래서 지난 날짜일수록, 넓은 검색어일수록 못 닿는다. 각 목록의 "얼마나 찾았나" 표에 검색어별 상태가 나온다.
- API 는 신문사를 고를 수 없어 넓은 검색어로 찾은 뒤 원문 주소로 7개사만 거른다. 조선비즈 같은 계열사는 뺀다.
- 사설은 제목이 `[사설]` 로 시작하는 글만 잡는다. 말머리가 없으면 일반 기사로 들어간다.
- 네이버 검색이 공백·따옴표를 어떻게 처리하는지는 확인 필요. 빅카인즈의 `AND` 는 공백으로 바꿔서 쓴다.

## 오류

키가 틀리거나(401), 호출이 막히거나(403), 하루 한도(25,000회, 429)를 넘기면 재시도·우회 없이 멈추고 오류를 보여 준다. 이때 목록은 저장하지 않는다.
