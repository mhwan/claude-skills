## 뿌리 원인

한국어는 **단어 경계가 공백으로만 표시되지 않고, 형태가 음절 안에서 융합된다.**
영어 기준으로 만들어진 정규식 관용구가 조용히 어긋난다. 셋 다 여기서 나왔다.

## 함정 1 — JS `\b` 는 한글 뒤에서 경계가 아니다

JS 정규식의 `\b` 는 `[A-Za-z0-9_]` 기준이다. 한글은 단어문자가 아니므로
한글 뒤에서 단어 경계가 성립하지 않는다.

```js
/운세\b/.test('[오늘의 운세/8월 21일]')   // false — 매치 안 됨
```

**파이썬은 다르다.** `re` 는 str 패턴에서 한글을 단어문자로 취급한다.

```python
re.search(r'운세\b', '[오늘의 운세/8월 21일]')   # 매치됨
re.search(r'운세\b', '[오늘의 운세계획]')        # 매치 안 됨 (의도대로)
```

**두 언어에 같은 규칙을 쓸 때 특히 위험하다.** `collect.js` 와 `cluster.py` 가
같은 칼럼 판별 규칙을 갖는데 한쪽만 어긋났다.

### 대응

경계를 명시한다.

```js
'(?=[\\s/\\]|·,.\\-–—:：]|$)'      // JS
```

## 함정 2 — 부분 문자열 매치

한글은 띄어쓰기가 없어도 자연스러워서 부분 문자열이 쉽게 걸린다.

```js
/오는/.test('카카오는 21일 이사회를 열고')   // true — '카카|오는' 으로 잘렸다
```

실제 사고: 과거 사실인 8월 21일 이사회가 **9월 21일 예정 일정으로** 브리핑에 올라갔다.
「나오는」·「보이는」·「들어오는」·「사오는」 등 같은 함정이 무수히 많다.

### 대응

```python
r'(?<![가-힣])오는'        # 앞에 한글이 오면 매치 안 함
```

숫자도 같다. 부분 문자열로 찾으면 「150조」가 본문의 「1500억」 안에서 발견된다.
→ 토큰 집합으로 비교한다.

## 함정 3 — 활용형을 음절로 나열

한국어 과거형은 어간에 따라 축약형이 제각각이다.

| 원형 | 과거형 | 음절 |
|---|---|---|
| 하다 | 했다 | `했` |
| 밝히다 | 밝**혔**다 | `혔` |
| 켜다 | 켰다 | `켰` |
| 펴다 | 폈다 | `폈` |
| 치다 | 쳤다 | `쳤` |

`(했|였|됐)` 만 적으면 「밝혔다」를 통째로 놓친다. 실제로 과거 서술 판정이 대량 누락됐다.

### 대응 — 자소 수준으로 판정

공통점은 **받침이 ㅆ** 이라는 것 하나뿐이다. 완성형 한글은

```
코드 = 0xAC00 + (초성 × 21 + 중성) × 28 + 종성
```

이므로 종성 인덱스를 직접 계산한다. ㅆ 은 20 번이다.

```python
def _has_ss_final(ch):
    c = ord(ch)
    return 0xAC00 <= c <= 0xD7A3 and (c - 0xAC00) % 28 == 20
```

**예외를 잊지 말 것** — 「있다」·「없다」는 받침이 ㅆ/ㅄ 이지만 과거형이 아니다.
「쉴 수 있다」가 과거로 잡혀 멀쩡한 일정이 버려졌다.
(「있었다」는 앞 글자가 `었` 이라 그대로 잡힌다.)

## 조사 처리

매체명·고유명사 뒤에는 조사가 붙는다. 뒤에 한글을 무조건 막으면 못 잡는다.

```
매경이 · 매경은 · 한겨레가 · 조선도
```

그런데 조사를 허용하면 복합어가 오탐으로 걸린다.

```
중앙은행 · 중앙정부 · 동아시아 · 조선업 · 조선족
```

**둘 다 처리해야 한다.** 조사는 허용하되 복합어는 명시적으로 뺀다.

```python
PARTICLE = r'(?:은|는|이|가|을|를|의|도|만|과|와|에|에서|으로|로)?'
NOT_OUTLET = re.compile(r'^(중앙(은행|정부|회|당|…)|동아(시아|…)|조선(족|업|…)|…)')
```

의미까지 봐야 할 때도 있다. 「조선 사설에 대한 반론이 없다」에서 조선은
부재의 **주어가 아니라 대상**이다. 주격·주제 조사(은/는/도/이/가)를 요구하면 걸러진다.

## 체크리스트

한글 패턴을 새로 쓰거나 고칠 때:

- [ ] `\b` 를 썼는가 → JS 라면 명시 경계로 교체. 파이썬이어도 의도를 확인
- [ ] 앞뒤 한글을 막았는가 → `(?<![가-힣])` / `(?![가-힣])`
- [ ] 활용형을 음절로 나열했는가 → 자소 규칙으로 대체 가능한지 검토
- [ ] 조사가 붙는 자리인가 → 허용하되 복합어 제외 목록을 두었는가
- [ ] 숫자를 부분 문자열로 찾는가 → 토큰 비교로
- [ ] 양일 실측 데이터로 오탐·누락을 **전수 확인**했는가
