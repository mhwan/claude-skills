## 하지 않는 것

### 차단 매체 직접 수집

중앙·한겨레·경향·매경은 robots.txt 로 `ClaudeBot`·`anthropic-ai` 를 `Disallow: /` 한다.
한국일보·국민일보·연합뉴스·KBS·JTBC 등도 마찬가지다. 네이버뉴스는 전면 차단.

robots.txt 는 기술 장벽이 아니라 **의사 표시**다. 브라우저로 열면 기술적으로 되지만
그건 UA 문자열 변조와 실질이 같다.

빅카인즈는 다르다. 한국언론진흥재단(공공기관)이 언론사와 콘텐츠 제공 협약을 맺고
운영하는 **공식 유통 채널**이고, robots.txt 가 `User-agent: * Allow: /` 다(GPTBot 만 차단).
우회가 아니라 정문이다.

> 소스를 늘릴 때는 **그 시점에 robots.txt 를 직접 확인한다.** 정책은 바뀐다.
> 여기 적어둔 목록을 믿지 않는다.

### UA 위장

`normalize.py` 의 링크 검사도 정직한 UA 를 쓴다.
실측상 위장이 손해였다 — 매경은 `Mozilla/5.0` 에 403, 정직한 UA 에 200 을 준다.

### 스케줄 자동 대량 수집

매경 `llms.txt` 가 허용 범위를 명시했다.

- 허용: 사용자 질의에 대한 실시간 검색·RAG·최소 범위 요약·출처 링크 제공
- 금지: 모델 학습·데이터셋 구축, 전문 영구 저장, 아카이브 재구성,
  제목+리드+본문을 조합해 원문 방문이 불필요할 정도로 재현

**수동 호출은 허용 범위에 가깝고, 스케줄 자동 대량 수집은 거부되는 쪽에 가깝다.**
자동화는 정책 재검토가 먼저다.

## 저작권 처리

본문 전문을 다루므로 필수다.

- 본문 전문은 **요약 생성을 위한 중간 데이터**로만 쓴다. 산출물에 전재하지 않는다
- 브리핑에는 자체 요약 + 제목 + 원문 링크 + 발행일 + 매체명만 싣는다
- 인용부호 안만 원문 그대로. 사설 1건당 누적 40자 이내
- 원문 방문을 대체할 정도의 상세 재현을 하지 않는다
- 출처(한국언론진흥재단 빅카인즈)를 문서 하단에 명시 — 렌더러가 자동 삽입
- **본문 전문을 영구 보관하지 않는다** — 브리핑이 검증을 통과하면 `prune.py` 로 폐기

### 폐기가 원칙인 이유

파이프라인은 본문 전문을 `raw/` 와 `work/*.todo.json` 에 **두 벌** 만든다.
매경 `llms.txt` 가 거부한 "전문 영구 저장"이 정확히 이 상태다.
용량(실측 6.4MB → 476KB)은 부수적이고, 원칙 위반이 본질이다.

`raw/` 만 제목·링크·발행메타로 남는다. 직전 7일 스테일 게이트(G4)가 제목을 읽기
때문이고, 제목은 브리핑에 이미 실린다. 본문·부제·개체명·유사도 벡터·감성은 지운다.

정리하면 **요약만 고쳐 다시 뽑을 수 없다.** `todo.json` 이 없으면 근거 게이트를
못 돌리는데, 검증 없이 재렌더하느니 수집부터 다시 하는 편이 낫다는 판단이다.

### 정리된 날짜는 파이프라인이 거부한다

`cluster.py` 와 `render.py prepare` 는 `raw['pruned']` 를 보고 종료코드 2 로 멈춘다.
막지 않으면 **조용히 통과한다** — 실측으로 `cluster.py` 가 exit 0 을 내면서
226건 중 201건을 '미분류'로 만들었다(`category` 가 없으니까). `render.py` 는 본문이
전부 빈 작업지시서를 만들고, 그러면 근거 게이트가 요약 전부를 '지어냄'으로 판정한다.
원인이 세 단계 앞에 있어서 찾기 어렵다.

## 알려진 한계

브리핑이 스스로 밝히도록 렌더러가 자동 표기하는 것과, 사람이 알고 있어야 하는 것.

| 한계 | 표기 |
|---|---|
| 매체당 일반 기사 30건 상한 | 헤더에 절삭 고지 자동 |
| 그날 그 쟁점에 논평 안 한 매체 | `⊘ 표본 내 미포착` 자동 (쟁점 단위) |
| 사설 0건 카테고리 | `🕳️ 공백` 에 사설/칼럼 구분해 자동 서술 |
| 카테고리 수동 교정 | `⟳` 자동 |

사람이 알고 있어야 하는 것:

- **경향신문 칼럼 0건.** 경향은 칼럼에 대괄호 말머리를 안 쓰고 URL 도 평평한
  `/article/{id}` 라 현재 신호로는 판별이 불가능하다. 논조 비교에서 이 비대칭을 감안할 것.
- **`[이혼의 세계]` 류 오탐.** 주제형 코너가 인물 칼럼 패턴에 걸린다.
  `byline` 으로 검증하려 했으나 39건 중 12건이 결측이고, 불일치 4건 중 3건이
  진짜 칼럼(필명을 쓴 기자, 외부 필자)이라 **조건으로 쓰면 진짜 칼럼을 잃는다.**
  「이혼」의 「이」도 성씨라 구조적 구분이 불가능하다. 수용한다.
- **의견 기사 카테고리 오분류.** 빅카인즈 분류를 그대로 쓴다.
  실측 오분류율 39%(18건 중 7건). 미래대응기금 사설이 정치로 분류되는 식.
- **클러스터 병합 미승격.** 희소 키워드 가드로 정밀도 100% 를 냈으나 표본이 얇아
  자동 병합하지 않는다. `merge_candidates` 로 표시만 한다.
- **`sentiment` 필드는 쓰지 않는다.** 사설 8건 중 6건이 `NEUTRAL` 이고
  🔴 강한 비판 2건이 정확히 `NEUTRAL`·빈값이었다. 기사 어휘 감성이지 매체 논조가 아니다.
- **근거 게이트가 못 잡는 것.** 숫자·인용 없이 서술만으로 인과관계를 지어내는 것은
  기계로 검증되지 않는다.
